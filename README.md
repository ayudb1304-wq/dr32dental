# Dr.32 Aesthetic Dental Care

One-page website for Dr.32 Aesthetic Dental Care, Horamavu Agara, Bengaluru.

Live preview: https://dr32dental.vercel.app (every push to `main` redeploys automatically).

- Plain HTML and CSS, no build step. Deploys as a static site on Vercel.
- Motion: GSAP 3.12.5 (self-hosted in `assets/js`). Respects reduced-motion settings.
- Fonts: Young Serif and Figtree, self-hosted in `assets/fonts` (SIL Open Font License).
- Patient quotes are from the clinic's public Google reviews.

Before launch: remove the preview note at the top of `index.html`, and add clinic photos and timings.
